# Sprint 1 — Planning

## Objetivo

Organizar la base del proyecto PetRescue Manager y definir las tareas iniciales del equipo.

## Tareas previstas

- Revisar y organizar el repositorio de GitHub.
- Definir el alcance inicial del proyecto.
- Preparar la documentación técnica inicial.
- Organizar las tareas en el tablero de GitHub.
- Repartir responsabilidades entre los integrantes.

## Responsabilidades

- **Pau:** backend y gestión de datos.
- **Arnau:** interfaz y diseño.
- **Ambos:** planificación, revisión y coordinación.

## Resultado esperado

Tener el repositorio organizado, las tareas iniciales definidas y la documentación básica preparada.

## Seguimiento

Se actualizará el estado de las tareas durante el sprint y se revisarán los resultados al finalizarlo.
