## Objetivo Principal del Repositorio

El objetivo principal de este repositorio es albergar el código fuente, la documentación técnica y los artefactos de diseño del proyecto **PetRescue Manager**. 

A través de este espacio de trabajo centralizado se gestionará el desarrollo completo de una aplicación web orientada a optimizar y centralizar la gestión operativa de protectoras y refugios de animales (control de animales, historial veterinario, adopciones, voluntarios y donaciones), garantizando el seguimiento metodológico ágil, el control de versiones y la colaboración continua del equipo.
